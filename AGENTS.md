# Инструкции для агента

- Интерпретатор: **Python 3.14.0**; после активации venv команды запускать через **`python`** (не `python3`), см. [README — раздел «Запуск API»](./README.md#запуск-api) и подраздел [«Какие команды считать эталоном»](./README.md#какие-команды-считать-эталоном).
- Активация виртуального окружения (`pyenv activate chess_venv` и т.д.) описана там же: [README — «Запуск API»](./README.md#запуск-api).

## Типизация (Pyright / basedpyright)

- **`typing.cast` по возможности не использовать.** Если тип «не сходится», править объявления у источника данных (например, метод **`Piece.serialize()` → `dict[str, object]`**, чтобы JSON-снимки фигур стыковались с **`battle_field`** без приведения).
- Для фабрик подклассов вместо **`type[Base]`** использовать **`Callable[[Arg], Base]`**, если у базового класса другая сигнатура конструктора, чем у подклассов (см. **`piece_from_dict`**).
- Поля ORM (Tortoise) с `null=True` при жёстких stub-ах лучше обновлять через **`Model.filter(...).update(...)`**, чем присваивать `None` в дескриптор, если анализатор ругается.
